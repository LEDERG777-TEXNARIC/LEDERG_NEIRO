# LEDERG NEIRO 0.1

Самостоятельный экспериментальный ИИ-проект для GitHub Pages. Сайт работает без отдельного backend, сторонних ML-библиотек и API.

## Состав проекта

- `index.html` — чат и лаборатория обучения.
- `styles.css` — адаптивный чёрно-красный интерфейс.
- `app.js` — чат, локальная история, обучение на собственных примерах.
- `model.js` — самописная нейросеть-классификатор на чистом JavaScript.
- `tests/model.test.js` — автоматические тесты.
- `.github/workflows/pages.yml` — тестирование и публикация через GitHub Actions.

## Как устроена модель

LEDERG NEIRO 0.1 — небольшой полносвязный MLP-классификатор намерений, а не большая генеративная языковая модель. Текст превращается в признаки слов и соседних пар слов; затем идут скрытый слой `tanh`, выход `softmax` и обучение обратным распространением ошибки (backpropagation).

Модель обучается в браузере на небольшом встроенном наборе примеров и фразах, добавленных пользователем. История и пользовательские примеры сохраняются в `localStorage` текущего браузера, а не отправляются на сервер.

### Честные ограничения

Это ранняя экспериментальная версия. Сеть определяет тему запроса, а ответ формируется встроенной логикой и шаблонами. Она пока не генерирует свободный текст на уровне ChatGPT, не ищет информацию в интернете и не исполняет переданный код. Для развития понадобятся дополнительные данные, тестирование и более развитая архитектура.

## Тесты

Нужен Node.js 20+. Установка зависимостей не требуется:

```bash
npm test
```

Для локального просмотра запусти статический сервер в корне проекта, например `python -m http.server 8080`, затем открой `http://localhost:8080`. Не открывай страницу через `file://`, поскольку браузер может блокировать ES-модули.

## GitHub Pages

Workflow запускает `npm test` на каждом push в `main` и после успешного тестирования публикует корень репозитория через GitHub Pages. В настройках репозитория открой **Settings → Pages** и проверь, что **Build and deployment → Source** установлен в **GitHub Actions**.
