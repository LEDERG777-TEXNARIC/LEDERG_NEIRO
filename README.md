# LEDERG NEIRO 0.4

A minimal chat-first LEDERG AI experiment published on GitHub Pages. Text answers are generated by an open-weight language model running in a dedicated browser Web Worker, keeping the chat interface responsive during model loading and generation.

## Language model

- **Model:** [Qwen2.5-0.5B-Instruct, ONNX Community](https://huggingface.co/onnx-community/Qwen2.5-0.5B-Instruct)
- **Runtime:** [Transformers.js 3.8.1](https://huggingface.co/docs/transformers.js/en/pipelines), loaded from a version-pinned CDN URL.
- **Inference:** dedicated Web Worker; WebGPU where supported, with a WASM/CPU fallback.
- **Quantization:** `q4` for both WebGPU and the WASM fallback, matching the documented Qwen2.5-0.5B-Instruct example.
- **Authentication:** no API key or hosted inference token is used. The browser downloads public model weights from Hugging Face and performs generation on the device.
- **System prompt:** a Russian-language prompt in `llm.js` defines LEDERG identity, accuracy, uncertainty handling, web-search honesty, coding guidance, and prompt-injection boundaries.
- **First use:** downloads roughly 800 MB of weights (varies with runtime/cache); later visits may reuse browser cache. The initial download can take time and uses local device memory/GPU.
- **Model scale:** 0.5B parameters is compact and experimental; answer quality is not comparable to large hosted models.

## User-facing features

- Minimal black-and-red chat interface; no developer/training panel.
- Local browser chat history.
- Curated knowledge retrieval from `knowledge.js` with source links. Relevant excerpts are passed to the language model as context.
- Live Wikipedia search through the public MediaWiki API; search snippets are passed to the language model, with source links in the answer.
- Direct Google, DuckDuckGo, and Wikipedia links when a broader search is needed. Direct search links are not represented as pages already read by the model.
- Current Moscow date/time via `Europe/Moscow`.
- Safe arithmetic and unit conversion handled locally.
- Current weather from Open-Meteo.
- Optional "Разбор" mode gives a concise explanation of the method and source types; it does not expose private internal reasoning.

## Files

- `index.html` — chat-only page.
- `styles.css` — responsive minimalist LEDERG UI.
- `app.js` — message lifecycle, tools, knowledge retrieval, web search context, and source links.
- `llm.js` — model loader, strong system prompt, prompt construction and generation wrapper.
- `knowledge.js` — curated Russian-language facts and source URLs.
- `tools.js` — Moscow time, safe calculator, unit conversion, Wikipedia search and weather.
- `model.js` — legacy small MLP-classifier experiment; it is no longer the text-generation engine.
- `tests/` — unit and regression tests for model adapter, tools, knowledge retrieval and chat UI.
- `.github/workflows/pages.yml` — tests then deploys the static website.

## Data and privacy

Chat history is stored in `localStorage` in the current browser and is not synced across devices. Prompts are processed by the local language model after its weights are downloaded. Search queries are sent to Wikipedia's public API; weather queries go to Open-Meteo. Do not submit secrets or sensitive personal data to web search. No secret API key is embedded in this public repository.

## Limitations

GitHub Models was retired on **July 30, 2026**, so this project does not use its retired inference API. Instead, Transformers.js runs an open model in the browser. The model is compact and may make mistakes or give shallow answers. WebGPU support depends on browser, OS and device; the WASM fallback may be slow. The app has no server-side browser-wide web-search provider: it queries Wikipedia, provides broad search-engine links, and passes retrieved snippets to the local model.

A true high-end general-purpose LLM requires a much larger model and considerably more compute. Prompt engineering cannot compensate for all limits of a 0.5B model.

## Tests and local preview

Requires Node.js 20+; no dependency installation is needed to run unit tests:

```bash
npm test
```

To preview the page, run a static server in the repository root, e.g. `python -m http.server 8080`, then open `http://localhost:8080`. Do not use `file://`; browser module imports and model fetching require an HTTP origin.

## Deployment

A push to `main` runs `npm test`. GitHub Actions deploys the root directory to Pages only if tests pass.
